# archive/

Superseded documents and the raw captures, kept for the record.  Nothing
here describes the current state: `docs/README.md` is the index, and
`docs/cam-state.md` is the camera's state.

The two machine-written session logs (`project-log.md` and
`compaction-log.md`) are not tracked: they were 16,000 lines of history
between them, and the git log has the same history in a form that can be
searched.  They are still on disk in this directory.
